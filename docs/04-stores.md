# Выкладка в App Store и Google Play

Приложение — тот же сайт (React), завёрнутый в оболочку Capacitor. Проекты лежат в `app/ios` и `app/android`.
Нативный код (Swift/Kotlin) писать не нужно. Всё, что отличает приложение из магазина от версии в Telegram, —
в `app/src/lib/telegram.ts` (ветка `isNative`): вибро-отклик, «Поделиться», кнопка «Назад», строка состояния.

## Как выпустить обновление (когда добавишь функции)

1. Правишь код как обычно, проверяешь на сайте.
2. `cd app && npm run sync:store` — собирает сайт для магазинов (с данными из `app/store-data`) и обновляет iOS- и Android-проекты.
   Если менялись «История аята» или комментарии Кулиева — сначала `npm run store-data` (пересобирает `store-data` из исходников).
3. Коммит и пуш в GitHub.
4. В Codemagic нажимаешь **Start new build** (iPhone и/или Android). Номер сборки растёт сам.
5. iPhone: сборка сама попадает в TestFlight → в App Store Connect выбираешь её и жмёшь «Отправить на проверку».
   Android: скачиваешь `.aab` из артефактов и загружаешь в Play Console.
6. Если менялась только вёрстка и тексты — это обычное обновление (проверка в Apple 1–2 дня).

Поднимать «версию» (1.0 → 1.1) нужно для каждого выпуска, который видят пользователи:
`MARKETING_VERSION` в `app/ios/App/App.xcodeproj/project.pbxproj` и `versionName` в `app/android/app/build.gradle`.

## Поворот экрана
Телефон: портрет везде, а в разделах для чтения (Коран, истории, хадисы, азкары, словарь) можно повернуть горизонтально —
список в `ROTATE` в `app/src/App.tsx`. iPad и планшеты Android: любой поворот везде. Логика — `allowRotation` в `app/src/lib/telegram.ts`.
Иконка и экран запуска делаются из `app/resources/logo-source.jpg` командой `npm run icons`.

## iPhone: пошагово

1. **Apple Developer** — оплатить программу, дождаться активации (до 2 дней).
2. **App Store Connect** (appstoreconnect.apple.com) → «Приложения» → «+» → новое приложение:
   - платформа iOS, название «Коран и Сунна» (если занято — добавь слово), язык основной — русский;
   - Bundle ID: `app.quransunna.reader` (сначала зарегистрируй его в разделе Certificates, Identifiers & Profiles → Identifiers);
   - SKU — любой, например `quran-sunna-1`.
3. **Ключ доступа для Codemagic**: App Store Connect → Пользователи и доступ → Интеграции → Ключи App Store Connect API → «+» (роль «Администратор»).
   Скачай файл `.p8` (скачивается один раз!), запиши Issuer ID и Key ID.
4. **Codemagic**: Teams → Integrations → App Store Connect → добавить ключ, назвать **codemagic** (имя важно — оно в `codemagic.yaml`).
   Подключи репозиторий `dinaraliev2002/quran-sunna`, выбери workflow «iPhone — App Store (TestFlight)», нажми Start new build.
5. Через 10–20 минут сборка появится в App Store Connect → TestFlight. Установи на свой iPhone приложение TestFlight и проверь.
6. Заполни карточку (тексты ниже), приложи скриншоты, выбери сборку, нажми «Отправить на проверку».

### Скриншоты для App Store
Нужен один набор для 6,9″ (iPhone 16/17 Pro Max): 1320×2868 px, 4–6 штук. Сделай их с телефона через TestFlight
(или попроси меня подготовить кадры с подписями). Приложение работает и на iPad, поэтому нужен ещё один набор для iPad 13″: 2064×2752 px (тоже 4–6 штук).

## Android: пошагово

1. **Ключ подписи** (создаётся один раз, хранить в надёжном месте — потерять нельзя):
   ```
   keytool -genkeypair -v -keystore quran-sunna.jks -keyalg RSA -keysize 2048 -validity 10000 -alias quran_sunna
   ```
   (нужен Java; либо создай ключ прямо в Codemagic: Code signing identities → Android keystores → Generate.)
   Загрузи его в Codemagic под именем **quran_sunna_keystore**.
2. **Play Console** → «Создать приложение» → название, язык русский, «Приложение», «Бесплатное».
3. Запусти в Codemagic workflow «Android — Google Play (.aab)», скачай `.aab`.
4. Play Console → Тестирование → Закрытое тестирование → загрузи `.aab`.
   **Для личного аккаунта, созданного после ноября 2023: нужно 12 тестировщиков и 14 дней закрытого теста** до выхода в «Производство».
5. Заполни разделы: «Политика конфиденциальности», «Безопасность данных», «Возрастной рейтинг», «Целевая аудитория».

## Данные для анкет (одинаковы для обоих магазинов)

- **Ссылка на политику конфиденциальности:** `https://<адрес сайта>/privacy.html` (файл `app/public/privacy.html`, публикуется вместе с сайтом).
- **App Privacy (Apple) / Data safety (Google):** данные **не собираются**, трекинга нет, реклама отсутствует.
  Приложение не требует регистрации (удаление аккаунта не нужно).
- **Шифрование (Apple):** только стандартное HTTPS — в проекте уже указано `ITSAppUsesNonExemptEncryption = false`.
- **Возрастной рейтинг:** 4+ / «Для всех» (нет насилия, азартных игр, UGC).
- **Категория:** Справочники (Reference) / Книги и справочники; для Google — «Книги и справочники».
- **Контакты поддержки:** бот `https://t.me/quran_sunna_app_bot?start=feedback` (Apple принимает ссылку; почту лучше добавить тоже).

## Что в магазинах, а что только в Telegram (решение от 2026-11-03)

- **В магазинах:** «История аята» только из аль-Вахиди; комментарии, словарь и места поклонов Кулиева; перевод Кулиева; тафсир ас-Саади.
- **Только в Telegram:** аль-Вадии, аль-Музайни, аль-Хиляли и Аль Наср — пока нет разрешения правообладателей.
  Источники в приложении не скрываются, подпись авторов остаётся.
- Устроено так: `app/store-data/` (собирается `npm run store-data`) подменяет данные в `dist` скриптом `app/scripts/apply-store-data.mjs`.
  Облачная сборка берёт данные из git, поэтому папка `store-data` должна быть закоммичена (она попадёт в публичный репозиторий).
- Дальше: найти свободные первоисточники и перевести их (или получить разрешения) — тогда добавить книгу в `STORE_BOOKS` в `app/scripts/build-asbab.py`.

## Риски проверки (прочти перед отправкой)

1. **Права на материалы (частично решено).** В репозитории не публикуются «Истории аята» (книги без разрешения правообладателей).
   Перевод Э. Кулиева и его комментарии к аятам — тоже чужие права: Apple и Google требуют, чтобы у тебя было
   право на весь контент, и по жалобе правообладателя приложение снимают. Перед выкладкой реши: либо получить
   разрешение (письмо издателя/наследников), либо оставить в версии для магазинов только материалы со свободной лицензией.
   Я могу сделать флаг сборки, который отключает спорные разделы в приложении из магазина.
2. **Правило 4.2 (Apple), «просто сайт».** В приложении есть всё нужное для прохождения: работа без интернета, вибро-отклик,
   жесты, нативное «Поделиться», заучивание. Если Apple откажет — в ответе будет конкретная причина, исправим.
3. **Кнопка «Поддержать проект»** в приложении открывает бота (не платёжную страницу). Внутри бота ссылка на Tribute
   в iOS-версии может вызвать вопрос у Apple; если вызовет — оставим только «Написать автору».
4. **Шрифты и аудио** берутся с серверов Quran.com (коммерческое использование их ресурсов лучше согласовать;
   в `fonts.ts` есть пометка перенести шрифты к себе).
