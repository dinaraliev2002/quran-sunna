# Шаг 2. Как запустить приложение на компьютере

Приложение лежит в папке `app`. Нужен Node.js (уже установлен).

## Запуск
1. Откройте терминал в VS Code: меню **Terminal → New Terminal**.
2. Выполните по очереди:
   ```
   cd app
   npm install
   npm run dev
   ```
3. Откройте в браузере адрес, который покажет терминал (обычно http://localhost:5173).
   Чтобы увидеть, как будет на телефоне: F12 → значок телефона (Toggle device toolbar).

Остановить: в терминале нажать **Ctrl + C**.

## Обновить данные Корана (обычно не нужно)
Текст, переводы, тафсир и раскладка страниц уже скачаны в `app/public/data`.
Если нужно скачать заново:
```
cd app
npm run data
```
Скрипт проверит, что аятов 6236 и страниц 604.

## Сборка для публикации
```
cd app
npm run build
```
Готовый сайт окажется в папке `app/dist` — её и нужно выложить на хостинг (см. шаг 3).
