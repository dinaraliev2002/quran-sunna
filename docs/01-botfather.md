# Шаг 1. Создать бота в Telegram

Бот нужен, чтобы открывать приложение внутри Telegram. Займёт 3 минуты.

1. Откройте в Telegram чат **@BotFather** (синяя галочка).
2. Отправьте команду `/newbot`.
3. Введите **название** бота. Его видят люди, например: `Коран и Сунна`.
4. Введите **username**. Он должен заканчиваться на `bot` и быть свободным, например: `quran_sunna_app_bot`.
5. BotFather пришлёт сообщение с **токеном** — длинной строкой вида `1234567890:AAH...`.

## ⚠️ Токен — это пароль от бота
- Никому его не показывайте и не публикуйте.
- Не присылайте его в чат, даже мне. Когда он понадобится (на этапе 2, для напоминаний), я создам файл `.env`,
  и вы вставите токен туда сами.
- Если токен случайно утёк: в @BotFather отправьте `/revoke` и получите новый.

## Что прислать мне
Только **username** бота (например, `@quran_sunna_app_bot`). Этого достаточно.

Кнопку, которая открывает приложение (`/newapp` или Menu Button), мы настроим позже,
когда появится адрес приложения в интернете. Сейчас делать ничего не нужно.
