# Окно слова: полный разбор слова — источники и как встроить (разобрано 05.11.2026)

Сейчас у каждого слова есть только русская подпись (`app/public/data/wbw`, 77 429 слов — столько же, сколько в морфологии QUL, ключ «сура:аят:слово» совпадёт).

## Какие данные нужны и откуда их взять
| Что показать | Источник | Права / заметки |
|---|---|---|
| Корень, основа слова, часть речи, падеж, форма глагола (I–X), время | Морфология QUL (qul.tarteel.ai, ресурсы «morphology / roots / lemmas / stems»; SQLite и JSON, 77 429 слов) — по сути Quranic Arabic Corpus v0.4 | У корпуса GNU GPL с условиями (в FAQ: исследование, без коммерции, ссылка на источник); QUL говорит, что лицензию надо смотреть у каждого ресурса. **Перед использованием проверить условия именно этих файлов; при сомнениях написать авторам (Tarteel / Kais Dukes).** |
| «Где ещё встречается» (все аяты с этим корнем или основой слова) | считаем сами по таблице корней | свои вычисления, права не нужны |
| Формы слова (масдар, причастия, прошедшее/настоящее/повелительное) | показывать **формы, которые реально есть в Коране** (из той же морфологии) — надёжно. Полные таблицы спряжения генерировать только для простых глаголов: у слабых (с буквами و ي ء) много исключений | библиотека Qutrub — GPL; своя генерация — права не нужны |
| Значение корня и применение в языке | Лексикон Лейна (англ., XIX в.; XML Perseus под CC BY-SA) — слишком объёмный для телефона и на английском; «аль-Муфрадат» ар-Рагиба аль-Исфахани (XI в.; свободен) — на арабском, для русского нужен перевод ИИ с проверкой | Лейн: лицензия на XML — CC BY-SA, нужно указать источник |
| Переводчик русский ↔ арабский | свободного арабско-русского словаря не нашли (Баранов, Борисов — под авторским правом; Wiktionary и Tatoeba — свободны, но данных мало) | реально только через платную переводческую службу или модель ИИ на сервере (бот в Supabase уже есть); платно за каждый перевод — решить отдельно |

## Как встроить в нынешние жесты
Сейчас: зажать аят → тафсир; двойной тап по слову → перевод слова.
Предложение: двойной тап по слову → то же маленькое окошко с переводом, но в нём кнопка **«Разбор»** → нижняя панель со вкладками: **Разбор** (корень, часть речи, форма) · **Где ещё** (список аятов с корнем, тап — переход) · **Формы**. Зажатие аята и тафсир не трогаем. Переводчик — отдельный раздел (вкладка в разделе «Словарь» или пункт в «Ещё»), а не часть Корана.

## Что ещё есть у Quranic Arabic Corpus (разобрано 06.11.2026)
Сайт corpus.quran.com, кроме морфологии (она у нас уже есть), предлагает:
- **Синтаксис и ирааб** («Syntactic Treebank», «Dependency Graphs», «Grammar (إعراب)»): роль каждого слова в предложении — подлежащее, сказуемое, дополнение, определение… Самое ценное для «полного разбора». Отдельный набор данных (дерево зависимостей).
- **Онтология понятий**: 300 понятий и 350 связей между ними; люди и места, упомянутые в аятах, привязаны к понятиям. Можно показывать «о чём аят» и искать аяты по теме. Понятия надо переводить.
- **Словарь корней**: «Verb Concordance», «Lemma Frequency», «Morphological Search» — частота слов и поиск по грамматике (например, все глаголы IV породы в совершенном времени). Это можно считать по нашим данным без внешнего источника.
- Условия те же: можно использовать при указании источника и ссылке на corpus.quran.com.
Что предложено сделать: 1) роль слова в предложении, 2) «Частые слова Корана» (учить слова по убыванию частоты, по нашим данным), 3) темы/понятия аята.
