# Заучивание Корана — подробный план (02.11.2026)

Основа уже есть для хадисов: `lib/hifz.ts` (карточки `{s, d}`, интервалы 1→3→7→14→30→60, оценки Хорошо/Средне/Плохо, пропуски, первые буквы, сборка), экран `/hifz`, сессии `Session.tsx`, блок «Повторить выученное» в «Сегодня». Для Корана **механику не переписываем, а обобщаем**: меняется единица заучивания, текст и проверка.

## 1. Единица заучивания — «отрывок»

- Отрывок = сура + диапазон аятов (`q2:255-257`). Короткая сура целиком — один отрывок.
- Длинное режем сами: примерно до 40–60 арабских слов (по концам аятов, лучше по смысловым границам; границы можно править, как «части» у хадисов).
- Ключ карточки: `q{сура}:{от}-{до}`. Префикс `q` рядом с `n`, `r`, `u`.
- Не делаем: отдельную карточку на каждый аят (их 6236, повтор превратится в кашу).

## 2. Где что находится

| Место | Что там |
|---|---|
| Раздел «Заучивание» (`/hifz`) | Две вкладки: **Хадисы** / **Коран**. Во вкладке «Коран»: «Сегодня» (новое + повтор), мои отрывки с прогрессом, подборки. |
| Читалка → окно аята | Кнопка «Учить с этого аята» → окно: до какого аята, назвать отрывок. Рядом с «Закладкой». |
| Читалка → шапка суры (`SurahBanner`) | «Учить суру» (вся или с аята N). |

| Главная → «Сегодня» | Одна задача «Повторить выученное»: «5 хадисов · 3 отрывка из Корана». Тап → общая очередь. |
| Профиль | Статистика: выучено аятов / сур / джузов, серия дней. |

### Подборки (готовые, чтобы не выбирать с нуля)
1. Джуз Амма (78–114) — по порядку «с конца», как принято у новичков.
2. Минимум для намаза: аль-Фатиха, аль-Ихлас, аль-Фаляк, ан-Нас, аят аль-Курси, 2 последних аята аль-Бакара.
3. Часто читаемые: Ясин, аль-Мульк, аль-Кахф, ар-Рахман, аль-Вакиа.
4. «Своё»: любая сура/диапазон из читалки.

## 3. Ступени урока (один отрывок)

Идём **цепочкой**: аят 1 → 1+2 → 1–3 … — так учат хуффазы, и это решает проблему «забываю связки».

1. **Слушать.** Аудио аят за аятом, повтор 3–5 раз (готовый режим `player.memo`: `repeatEach`, `repeatRange`, `hideText` в Reader). Текст с таджвидом + пословный перевод (`ru-quranwbw`, есть) и общий перевод.
2. **Читать вместе.** Текст виден, играет чтец, подсвечивается слово/аят.
3. **Пропуски:** каждое 3-е слово → каждое 2-е → всё скрыто (арабские слова берём из `w`, они уже отдельно). Подсказка по тапу: слово + перевод слова.
4. **Слова через одно / через два** (необязательно): видно каждое 2-е (или 3-е) слово, остальные скрыты.
5. **«Продолжи аят»** (главная для Корана проверка): показан аят, нужно прочитать следующий; по тапу — открыть и оценить себя. Вариант-тест: «Какой аят следующий?» из 3 вариантов (подбираем похожие по началу — это ловит ошибки в похожих местах).
6. **Сборка аятов** из перемешанных (по желанию, для 4+ аятов).
7. **Оценка:** Хорошо / Средне / Плохо → тот же `schedule()`.

Пользователь может отключить 4 и 6 (как у хадисов: «по желанию»).

## 4. Повторение

- Тот же ряд 1→3→7→14→30→60 и те же три оценки. Выученным считаем со ступени `LEARNED_STAGE`.
- В повторе: показан **русский перевод**, арабский размыт; тап → становится чётким + играет аудио (решение 24.10). Самооценка.
- Свежие отрывки (< 7 дней) — отдельной группой «Свежее», каждый день.
- Для давних отрывков в будущем: «Круг» — раз в день прочитать вслух по 1 джузу из выученного (метод «манзиль»). В v1 не делаем.
- Если пользователь пропустил дни: просроченные не копятся лавиной, на день показываем не больше N (по умолчанию 10) самых старых, остальное сдвигаем.

## 5. Хранение (важно!)

- Облако Telegram: **не больше 4096 символов на ключ**. Один `hifz_v1` для хадисов уже близок к границе при сотнях карточек.
- Для Корана новый формат и **несколько ключей**: `hifzq_1`, `hifzq_2` … Запись компактная: `сура.от-до:ступень:день` в base36 (≈10 символов на карточку → ~400 карточек в ключе); при переполнении — следующий ключ.
- Дополнительно: `hifzq_cfg` — норма в день, чтение/пропуски/буквы вкл/выкл, разбиение отрывков.
- В `settings.ts`: `quranHifz: Record<string, HifzCard>`, `qhSplit`. Действия `hifzLearn/Grade/Reset` обобщить до работы с префиксом `q`.
- Слияние при синхронизации (`_t`) — как у существующих ключей.

## 7. Порядок работ

1. Модель: отрывок, ключ, хранение в нескольких ключах, обобщённый `schedule`. Без интерфейса — проверить на данных.
2. Экран «Заучивание» → вкладка «Коран»: подборки, «Учить суру/с аята» из читалки, прогресс по сурам.
3. Урок: ступени 1–3 и 7 (слушать, читать, пропуски, оценка). Выпустить на тест.
4. Ступени 4–6 («Продолжи аят», слова через одно/два, сборка).
5. Повтор: размытый арабский + перевод + тап для аудио, общая очередь на главной.
6. Профиль/статистика, пометки в списке сур.
7. Потом: Tarteel (бесплатно — всем / платно — в подписку), ИИ-проверка голосом, «Круг» для давних, похожие аяты (муташабихат), связка с тафсиром.

## 8. Решения пользователя (02.11.2026)

- **Вместо «первых букв» — видимые слова через одно или через два** (остальные скрыты). Первые буквы арабских слов не делаем. Ступень 4 в уроке заменяется: «слово через слово» → «слово через два слова».
- **Норма в день — в аятах**, рядом подсказка «≈ N строк мусхафа».
- **Подборка по умолчанию — с конца Корана, 30-й джуз (Джуз Амма)**; дальше человек сам выбирает суры.
- **Ничего не публикуем для всех.** Всё делаем и проверяем в тесте (`npm run deploy:test`); `npm run release` только после проверки и явного «выпускай». Новые идеи по ходу добавляем в план и выпускаем окончательный вариант.
- Почему заучивание шло после пословного перевода — пользователь забыл; вероятно: перевод слова — подсказка при скрытых словах и опора для понимания. Использовать `wbw` в уроке и повторе.
