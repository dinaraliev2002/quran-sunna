# Фоны для карточек «Аят дня» / «Хадис дня» / «Поделиться картинкой»

Сейчас «Картинкой» рисует карточку на canvas (`app/src/lib/shareImage.ts`): бежевый/тёмный фон темы, золотые уголки.

Как хочет Динар (05.11.2026):
- по нажатию «Поделиться картинкой» открывается окно с предпросмотром — так, как будет выглядеть картинка;
- внизу стрелки вправо/влево: листать варианты (вид 1 — одна картинка-фон, вид 2 — другая и т.д.);
- фонов 20–50, но они не должны утяжелять приложение: лёгкие или подгружаются только когда дошли листанием;
- текст поверх с затемнением для читаемости.
Сначала только в тестовой версии.
