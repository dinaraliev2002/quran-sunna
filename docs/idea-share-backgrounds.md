# Идея на потом: фоновые картинки для карточек «Аят дня» / «Хадис дня»

Сейчас «Картинкой» рисует карточку на canvas (`app/src/lib/shareImage.ts`): бежевый/тёмный фон темы, золотые уголки.

Что добавить позже (пожелание Динара, 31.10.2026):
- коллекция примерно 20–50 фоновых картинок (природа, небо, орнамент, мечети);
- выбор фона перед отправкой, текст поверх с затемнением для читаемости;
- картинки лежат в `app/public/share-bg/`, на canvas рисуются через `drawImage` до текста;
- чтобы публиковать красивые карточки в соцсетях.
