# Разбор приложения «Арабский словарь и спряжение» (Qamus, io.arabic.dictionary) — 13.11.2026

Версия 2.17.2 (APKPure), Flutter, база Isar. Скачано в `D:\qamus-apk` (`qamus.apk`, `qamus.xapk`; вне репозитория). Скрипт чтения базы: `D:\qamus-apk\work\extract.py` (длина 3 байта + UTF-8, см. ниже).

## Что внутри
- **Словарь — в самом приложении**, файл `assets/flutter_assets/assets/articles.sqlite` (68 МБ; по имени SQLite, на деле база Isar/libmdbx, `libisar.so`). Строки лежат как «длина (3 байта, little-endian) + UTF-8». Прочитано ~539 тыс. строк: ~326 тыс. арабских и ~213 тыс. русских.
- **Статья существительного:** слово с огласовками → корень → «слитая» форма для поиска (вроде `برىدات برىد`) → родственное слово → русская статья Баранова (с `\n`, нумерацией, арабскими вставками с маркерами направления).
- **Глагол хранится пятью формами:** повелительное, прошедшее, настоящее, масдар, страдательное прошедшее (например `اِنْتَحِلْ / اِنْتَحَلَ / يَنْتَحِلُ / اِنْتِحَال / أُنْتُحِلَ`), с корнем и породой.
- В коде классы: `Article`, `ArticleNoun`, `ArticleVerb`, `ArticleTranslation`, `FavoriteArticle`, `ArticleNoteRecord`, `ViewedArticleRecord`, `VerbConjugation`, `Tense`, `VerbVoice`.
- Русский словарь Баранова «исправленный и дополненный» — собственность разработчика; права на сам словарь Баранова нужно уточнять отдельно.

## Спряжение
- **Полной таблицы спряжения в приложении нет.** Берётся с сервера: пути `/tasrif`, `/verb_conjugation` на `https://api.qamusapp.com` (модели `VerbConjugation`, `VerbConjugationValues`, `TenseGroup`, залоги действительный/страдательный, времена). Значит, формулы спряжения у них на сервере.
- Дальше в приложении только показ: таблица и список, выбор залога и времени.

## Остальное (через сервер, платно по подписке RevenueCat)
ИИ-перевод с огласовками, грамматический разбор (`/ai/grammatical-analysis`), чат, примеры, карточки, перевод по фото, диктовка; синхронизация коллекций (`/collections/sync`), публичные коллекции, интервальное повторение (карточки, тесты), награды. Аналитика PostHog, Firebase.
